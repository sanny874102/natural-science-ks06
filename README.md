# 6上康軒自然線上練習大題庫

依據 115 學年度康軒版六年級上學期自然第一次段考解答製作，採單頁靜態網站，可直接以 GitHub Pages 部署。

## 題庫

- 共 174 題／題組：55 題是非、83 題選擇與綜合觀念題、36 組複合題。
- 36 組題組的文章、圖表和子題會一同顯示在同一頁；每組作答完畢後才可前往下一題。
- 支援隨機抽選 10、25、50 題，或完整題庫。題數以題目／題組計算，得分按小題計算。
- 圖表以 SVG 或 HTML 直接嵌入頁面。

## GitHub Pages

在儲存庫 Settings → Pages 將來源設為 main 分支根目錄即可部署。網站入口是 `index.html`.
